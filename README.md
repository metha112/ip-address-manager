# MS Network Calculator - IP Address Manager

IP Address / Subnet Calculator for University Project.

## 📁 Project Structure
- `windows-version/` - Desktop application (Windows) - C & GTK
- `web-application/` - Web-based version - HTML/CSS/JS

## ✨ Features
- IP allocation & tracking
- Subnet calculation
- Network / Broadcast address
- Search & filter IPs

## 🛠️ Tech Stack
- Windows Version: C Language, GTK Library
- Web Version: HTML, CSS, JavaScript

## 🚀 How to Run
### Windows Version
1. Go to `windows-version/` folder
2. Compile: `gcc main.c -o MS_Network`
3. Run `MS_Network.exe` (dll tika ekama folder eke thiyenna ona)

### Web Application
1. Go to `web-application/` folder
2. Open `index.html` in browser

## ⚠️ NOTE
MS_Network.exe eka run karanna DLL files okkoma ekama folder eke thiyenna ona.
